# Design Document

## UI/UX Design
- **Framework CSS**: Tailwind CSS / Bootstrap
- **Prinsip**: Responsive Design, Clean UI, User-Friendly

## Peran Pengguna & Akses
- **Admin (Pemilik Kos)**: Dashboard manajemen penghuni, kamar, transaksi, dan laporan perbaikan.
- **Penghuni**: Halaman profil, riwayat tagihan, pengajuan perbaikan, pengumuman.
- **Calon Penghuni**: Landing page, katalog kamar kosong, form reservasi & pertanyaan.
