# Product Requirements Document (PRD): Aplikasi Web Manajemen Kos

## 1. Pendahuluan
Mengelola usaha kos sering kali melibatkan banyak pekerjaan manual (mencatat data, memantau pembayaran, menangani perbaikan). Aplikasi web ini menyederhanakan proses tersebut menjadi pusat manajemen penghuni, komunikasi, dan pemesanan kamar agar lebih efisien dan ramah pengguna.

## 2. Fitur Utama
- **Sistem Manajemen Penghuni**: 
  - Profil Penghuni
  - Pelacakan Pembayaran
  - Manajemen Kontrak
- **Platform Komunikasi**: 
  - Permintaan Perbaikan
  - Pengumuman
  - Pesan Langsung
- **Sistem Booking**: 
  - Ketersediaan Kamar
  - Pemesanan Online
  - Formulir Pertanyaan
