# Project Rules

## Development Rules
1. Gunakan format JSON untuk payload API.
2. Gunakan `camelCase` untuk penamaan variabel & fungsi di kode.
3. Gunakan `snake_case` untuk penamaan kolom dan tabel database.
4. Simpan konfigurasi sensitif (DB password, secret keys) di file `.env`.
5. Terapkan validasi input pada sisi client dan server.
