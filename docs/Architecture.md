# Architecture Document

## Arsitektur Sistem
- **Frontend**: React.js
- **Backend**: Node.js dengan Express (RESTful API)
- **Database**: MySQL / PostgreSQL
- **Deployment**: Vercel/Netlify (Frontend), Heroku/DigitalOcean (Backend)
- **Keamanan**: SSL/TLS

## Integrasi Masa Depan
- Payment Gateway (QRIS / E-Wallet)
- WhatsApp API untuk Notifikasi
